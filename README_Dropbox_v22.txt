FUNERALPLANER – DROPBOX OHNE WEBSITE

Die App verwendet Dropbox als zentralen Speicher für den Katalog. Es ist keine eigene Website und keine localhost-Redirect-Adresse erforderlich.

1. „Mit Dropbox verbinden“ wählen.
2. Dropbox öffnet die Anmeldung in einem neuen Fenster/Tab.
3. Dropbox zeigt nach der Zustimmung einen Autorisierungscode an.
4. Zur FuneralPlaner-App zurückgehen und „Dropbox-Code eingeben“ wählen.
5. Code einfügen. Danach „Cloud speichern“ bzw. „Cloud laden“ verwenden.

Die App verwendet OAuth 2.0 mit PKCE.

Hinweis: Dropbox ist der Datenspeicher. Eine HTML-Datei in einem Dropbox-Ordner ist auf dem iPhone nicht automatisch eine installierbare Web-App. Das iPhone-Verhalten muss separat getestet werden.
